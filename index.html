Main Features & Functions

This app plays your favorite songs smoothly without using heavy graphics or distracting layouts, keeping your computer running light and fast.

Key Highlights:

  • ✓ YouTube Audio Streaming: You can use special keys to look up and stream music directly from YouTube into the app.
  • ✓ Sound Equalizer Presets: Cycle through different audio configurations (like Rock, Pop, or Flat) to match your music style.
  • ✓ Visual Time Clock: Watch the track time update frame-by-frame with a big, creative retro text design.
[ TRACKLIST ]
File Compatibility

The player includes a built-in music browser that directly scans your folders to locate your songs automatically.

  • • Supported Audio: .mp3, .wav, .ogg, .flac, .m4a
  • • Live Playlist: Keeps your tracklists organized
  • • Quick Loading: Instantly jumps to any folder
[ AUDIO CONFIG & CONTROLS ]
Keyboard Control Guide

Use these keys to manage playback execution inside the dashboard:

SPACE : Play / Pause song

▲ / ▼ : Turn Volume Up / Down

N / P : Next / Previous track

Y : Stream from YouTube

F / TAB : Browse folder system

S / Q : Stop track / Quit player
