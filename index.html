MASCII v1.1.0

A minimalist, terminal-based hybrid music player engineered under a strict keyboard-driven control scheme and pure typography layouts.

  • • Codename: Kingston Stable Release
  • • Engine Stack: Node.js Ecosystem
  • • UI Wrapper: Blessed Architecture Grid
  • • Output Target: Standard Terminal Buffer
[ PLAYER CAPABILITIES ]
Stream Pipelines & Audio Optimization

MASCII natively processes local tracks and remote streams with zero graphical overhead, ensuring low memory foot-prints across development setups.

Key Features Built In:

  • ✓ YouTube Streaming Core: Dedicated background wrappers stream remote media directly into the command line shell using specific key triggers.
  • ✓ Live Equalizer Engine: Real-time hardware preset cycles (Rock, Pop, Flat, etc.) for customized listening environments.
  • ✓ Big ASCII Display Matrix: High-legibility custom typographic font matrix updating frame-by-frame for elapsed tracking times.

"Audio fidelity shouldn't depend on high-overhead graphical frameworks."

[ FILE SYSTEM INTEGRATION ]
Reactive Browser

The framework hosts an asynchronous native file tree explorer inside core/ui.js that monitors local files system blocks.

  • • Supported Formats: .mp3, .wav, .ogg, .flac, .m4a
  • • Asynchronous Tree Mapping (fs.readdirSync)
  • • Live Playlist Data Caching Layer
[ KEYBOARD SHORTCUTS REFERENCE ]
Global Event Mapping Matrix

The runtime interface relies on targeted global listener keypress matrices:

SPACE : Play / Pause Toggle

▲ / ▼ : Volume Master Up / Down

N / P : Skip Next / Previous Track

L : Toggle Loop Sequences

F / TAB : File System Browser Overlay

S / Q : Stop Engine / Safe Exit
